四、 標準熱力學轉換與計算公式

標準熱力轉換基準： 1 RT = 3.516 kW

1. 既有設備年用電量 ($E_{old}$)

※ 實際 COP = 額定 COP × (1 - {{ params.decayRate/100 }})^運轉年數 = {{ params.oldCOP }} × ({{ (1 - params.decayRate/100).toFixed(3) }})^{{ params.oldYears }} = {{ results.actualOldCOP }}

=[ (RT × 3.516) / 實際 COP ] × 年運轉時數

=[ ({{ params.oldRT }} × 3.516) / {{ results.actualOldCOP }} ] × {{ params.hours }}

= {{ formatNum(results.oldEnergy) }} kWh/year

2. 新設設備年用電量 ($E_{new}$)

※ 變頻主機 IPLV = 0.01A + 0.42B + 0.45C + 0.12D

※ IPLV = 0.01({{params.newCop100}}) + 0.42({{params.newCop75}}) + 0.45({{params.newCop50}}) + 0.12({{params.newCop25}}) = {{ calculatedIPLV }}

=[ (RT × 3.516) / IPLV ] × 年運轉時數

=[ ({{ params.newRT }} × 3.516) / {{ calculatedIPLV }} ] × {{ params.hours }}

= {{ formatNum(results.newEnergy) }} kWh/year

五、 節能效益與減碳貢獻計算過程

A. 節能量 ($\Delta E$)

= $E_{old}$ - $E_{new}$

= {{ formatNum(results.oldEnergy) }} - {{ formatNum(results.newEnergy) }}

= {{ formatNum(results.energySavings) }} kWh/year

B. 節能率 (%)

= ($\Delta E$ / $E_{old}$) × 100%

= ({{ formatNum(results.energySavings) }} / {{ formatNum(results.oldEnergy) }}) × 100%

= {{ results.savingRatio }} %

C. 年減碳量 (Carbon Reduction)

= $\Delta E$ × 電力排放係數

= {{ formatNum(results.energySavings) }} × {{ params.emissionFactor }}

= {{ formatNum(results.carbonReduction) }} kg CO₂e/year

D. 年省電費 (Cost Savings)

= $\Delta E$ × 每度電費

= {{ formatNum(results.energySavings) }} × {{ params.electricityRate }}

= {{ formatNum(results.costSavings) }} NTD/year
